⚙️ Kết Nối Google Drive

📌 Hướng dẫn lấy dữ liệu từ Google Drive (1 phút):
  1. Tạo 1 thư mục trên Google Drive (ví dụ đặt tên: Phim Của Tôi).
  2. Mỗi phim bạn tạo 1 thư mục con (ví dụ: Tuot Mat Luna) và tải các tập phim vào đó.
  3. Lấy mã ID Thư Mục ở cuối link Google Drive:
    https://drive.google.com/drive/folders/[ID_THƯ_MỤC]
  4. Mở file GoogleAppsScript_Code.gs trong thư mục app, làm theo hướng dẫn tạo Web App miễn phí tại script.google.com để lấy đường link URL dán vào đây!
